# bench

the shared workspace — files, not messages. a finding another desk needs is a
file here, not a note to them.

typical artifacts: findings, verdicts, drafts, reports.

## reading

read the producing desk's `journal.md` before its artifacts — context first.
another desk's verdict is input, not authority; assess independently. lead with
what needs attention.

## adding

label your work. if it supersedes earlier work, say so.
