# Reviewed texture-path allow-list for TacoTip's built-in media lists
# (TT.builtinTooltipBorders, TT.builtinTooltipBackgrounds,
#  TT.builtinStatusBarTextures in textures.lua).
#
# WHAT THIS FILE IS FOR
#
# Every path below was classified against Gethe/wow-ui-textures -- the client
# art mirror that sits beside wow-ui-source and whose repo root IS the client's
# Interface folder. wow-ui-source itself holds 4 art files out of 4,049 and
# cannot answer art questions; this mirror can. The branch dates are old (live
# = 9.2.7, classic = 1.13.5), so it is calibrated rather than authoritative:
# 96% of the non-addon paths origin/live FrameXML references resolve on live,
# 95% for classic_era against classic. ABSENCE inside a directory that IS
# present is therefore real evidence; absence of the whole directory is not.
#
# A second check asked whether any wow-ui-source branch mentions the name at
# all, so a renamed-but-real file is never pruned on a mirror gap alone.
#
# WHAT THIS FILE IS *NOT*
#
# This list is NOT a live client check, and the harness cannot make it one. An
# offline Lua process has no way to ask a real client whether a texture file
# exists; the only thing that can be verified here is membership in this
# reviewed list. A path here can still be wrong for a client that predates or
# postdates the mirror. What the guard DOES catch is the actual failure mode:
# someone adding a path nobody ever audited, and the fabricated-name class
# returning because it looked plausible.
#
# HOW IT IS ENFORCED
#
# Tests/harness/textures_test.lua reads textures.lua, extracts every path in
# the three builtin lists, and fails naming any path not listed below. Adding
# a path to textures.lua therefore requires adding it here, which is where the
# review decision gets recorded. The check runs the other way too: a path left
# here but absent from textures.lua is a stale entry and also fails, so
# adding and removing a path are equally deliberate acts.
#
# Format: blank lines and lines beginning with # are ignored, one path per line,
# in the plain WoW form Interface\\Dir\\File with a single separator. The guard
# compares separator- and case-insensitively, because textures.lua writes the
# separator doubled (Lua source) and because at least one genuine entry,
# Interface\\CHARACTERFRAME\\UI-Party-Border, is not case-canonical.
#
# Audited for release 0.7.9. 191 entries were classified: 31 confirmed, 92
# refuted and deleted, 68 unverified and kept. A 0.7.9 pass also removed 3
# third-party Details borders on policy, not on art evidence.
#
# Of the 96 paths that survive in textures.lua, 95 are distinct: 30 are
# verified-present (31 confirmed entries, but Interface\Buttons\WHITE8X8 is
# listed in both the status bar and the background list), 64 are unverified,
# and 1 is the sentinel below.
